# Amazon Clone

A front-end clone of the Amazon website built for educational and learning purposes.

## About

This project was created to practice and improve web development skills using HTML and CSS. The design and layout are inspired by the Amazon website and were recreated as part of a personal learning project.

## Features

* Responsive navigation bar
* Hero banner section
* Product card layouts
* Recommendation section
* Multi-column footer
* HTML & CSS based design
* Responsive layout practice

## Technologies Used

* HTML5
* CSS3

## Purpose

The purpose of this project is:

* Learning HTML structure
* Practicing CSS layouts
* Understanding responsive design
* Improving front-end development skills
